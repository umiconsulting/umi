# Dashboard localization

The dashboard speaks Spanish and English. Spanish is the source language: the text in the JSX is
Spanish, and the English catalog translates it. The decision record is
[docs/architecture/2026-09-05-dashboard-i18n-library-decision.md](../../../docs/architecture/2026-09-05-dashboard-i18n-library-decision.md).

## How the locale is chosen

1. The owner's saved choice in the browser (`localStorage` key `umi.dashboard.locale`).
2. The café record (`merchant.locale`, for example `es-MX`), only when the owner has not chosen.
3. The browser language.
4. Spanish.

The language selector is in the sidebar foot. A change applies at once and persists in the browser.
`<html lang>` follows the active locale.

## Write localized text

- JSX text: `<Trans>Guardar cambios</Trans>`.
- Attributes and plain strings inside a component: `const { t } = useLingui();` then
  `aria-label={t`Cerrar`}`.
- Module-level constants: `msg`Resumen`` and resolve at render with `i18n._(descriptor)`.
- Plain JS modules (no React): `import { t } from '@lingui/core/macro'` and call `t` inside a
  function, never at module scope.
- Plurals: `<Plural value={n} one="# visita" other="# visitas" />`.
- Two meanings for one word: add `context`, for example
  `<Trans context="order status">Listo</Trans>`.
- Numbers, money, and dates: use `src/lib/format.js`. Do not call `toLocaleString('es-MX')`.

Brand and product names stay as plain strings: Umi, UmiPOS, UmiKDS, Umi Cash, ConversaFlow,
WhatsApp, Wallet, KDS, POS.

## Commands

| Command             | Effect                                                                            |
| ------------------- | --------------------------------------------------------------------------------- |
| `pnpm i18n:extract` | Update `src/locales/{es,en}/messages.po` from the source.                         |
| `pnpm i18n:compile` | Write `src/locales/*/messages.mjs` and fail on a missing translation.             |
| `pnpm lint`         | `lingui/no-unlocalized-strings` reports every owner-facing string outside Lingui. |

`predev`, `prebuild`, and `pretest` run the compile step, so the compiled files are never committed.

## Add a locale

1. Add the tag to `locales` in `lingui.config.js`.
2. Add `{ tag, label, bcp47 }` to `LOCALES` in `src/lib/i18n.js`.
3. Run `pnpm i18n:extract` and translate `src/locales/<tag>/messages.po`.
4. Run `pnpm i18n:compile`.

## Translate

Edit the `msgstr` lines in `src/locales/en/messages.po`. PO files open in Poedit, Crowdin, Lokalise,
and Weblate. The `#.` comment above a message names the expression behind each `{0}` placeholder.

## Tests

`src/test/i18n.jsx` loads both compiled catalogs and activates Spanish. Wrap a rendered component
with `withI18n(...)`, and call `activateTestLocale('en')` to assert English text.
