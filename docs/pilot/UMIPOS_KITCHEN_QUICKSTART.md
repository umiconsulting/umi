# Guía rápida para cocina

1. Confirma el emparejamiento y la estación de KDS.
2. Confirma el heartbeat y la instantánea inicial.
3. Abre la orden entrante.
4. Marca el inicio de preparación.
5. Marca cada producto como listo.
6. Marca la orden como lista y después como completa.

Usa la prioridad solo para una decisión operativa real. Usa `Recall` para recuperar una orden terminada.

Si KDS pierde conexión:

1. Conserva el orden físico actual.
2. Espera la reconexión automática.
3. Confirma la nueva instantánea.
4. Revisa cancelaciones y cambios antes de continuar.
5. Escala una ruta incorrecta al Manager.

El Dashboard administra estaciones y rutas. Solo el contexto KDS cambia el estado de preparación.
