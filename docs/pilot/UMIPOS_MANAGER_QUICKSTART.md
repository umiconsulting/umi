# Guía rápida para Manager

## Responsabilidades

- Aprueba operaciones dentro de su límite.
- Ejecuta reembolsos autorizados.
- Registra ajustes, conteos y conciliaciones de inventario.
- Revisa las variaciones de caja.
- Ejecuta diagnósticos de hardware.
- Ajusta loyalty y administra gift cards según la política.
- Resuelve excepciones de cocina y del Centro de recuperación.
- Escala los problemas de autoridad, datos o infraestructura.

## Aprobación

1. Revisa la vista previa y el motivo.
2. Confirma el importe y el alcance.
3. Usa tu propia credencial.
4. Regresa al comando original.
5. Confirma el resultado final.

Una aprobación sirve para una huella de comando. No reutilices una aprobación.

## Límites

Solicita al Owner o Admin estos cambios:

- usuarios y permisos;
- políticas y límites;
- configuración de hardware;
- administración completa del comercio;
- decisiones de gift cards fuera del límite;
- auditoría o recuperación restringida.
