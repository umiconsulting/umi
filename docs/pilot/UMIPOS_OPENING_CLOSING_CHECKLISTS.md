# Listas de apertura y cierre de UmiPOS

## Apertura diaria

- [ ] Confirma que el indicador de la API está disponible.
- [ ] Confirma la versión de UmiPOS y el entorno `pilot`.
- [ ] Confirma la confianza del dispositivo.
- [ ] Inicia sesión con el PIN personal.
- [ ] Confirma la ubicación y la caja.
- [ ] Abre el turno y registra el fondo inicial.
- [ ] Ejecuta las pruebas de la impresora, el cajón y el escáner.
- [ ] Confirma la estación de KDS y su conexión.
- [ ] Revisa las alertas de inventario y el Centro de recuperación.

Detén la apertura si la ubicación, la caja o el dispositivo son incorrectos.

## Cierre diario

- [ ] Termina o suspende las ventas abiertas.
- [ ] Resuelve las órdenes activas de KDS.
- [ ] Revisa el Centro de recuperación y los comandos de hardware pendientes.
- [ ] Registra los retiros de efectivo antes del conteo.
- [ ] Haz el conteo ciego y revisa la variación.
- [ ] Solicita la aprobación cuando la política la requiera.
- [ ] Cierra el turno.
- [ ] Registra las excepciones de inventario para revisión.
- [ ] Confirma que el servicio muestra un estado saludable.
- [ ] Cierra la sesión del operador.

El cierre diario no incluye la administración de respaldos. Soporte técnico administra los respaldos.
