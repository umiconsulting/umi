- Pass: `docs/research/2026-09-18-purchase-orders-competitive/`.
- Tool: Playwright Chromium (1.62.1 and 1237) rendered the live host; `curl` 8.5.0
  with a Chrome user agent fetched the product images, one YouTube frame, and one PDF;
  `ffmpeg` wrote the video frame; `pdftotext` read the PDFs.

  this research folder with their source URL. Do not rehost them in a product or a
  marketing page.

  The `.gitignore` entry at the repository root holds the rule and the reason; 14
  curated images are committed beside this index, and the other 29 stay
  reproducible from the source URL recorded here.

This is the master list. Each lane file beside it holds the full narrative and the
route-failure log; each lane table is reproduced below, verbatim. The column set
differs between lanes where the lane recorded a different set of facts.
